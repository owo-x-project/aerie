## 何を残すか

- 計画 plan.md やることの一覧。済んだものには印が付く
- 気づき notes.md 作業中に分かったこと。足すだけ
- 引きつぎ handoff.md 今どこまで来ていて、次に何をするか

置き場は `.aerie/memory/<ブランチ名>/`。どれも書くときに自動で作られる。

## 計画

```sh
scripts/plan.sh <<'PLAN'
- ルールを決める
- スキルを作る
PLAN

scripts/done.sh 1 3
scripts/done.sh -u 2
```

行の頭の印はそろえられるので気にしなくてよい。plan.sh は全文の書き直し。
進んだときは done.sh で印を付けるだけにして、書き直さない。

## 気づき

```sh
scripts/note.sh '検査は同じ名前のファイルで走らせないと当たらない'
```

一行ずつ足す。あとで読み返して、きまりや案件のスキルに直すための材料。
次にも効くことだけ書く。その場かぎりのことは書かない。

## 引きつぎ

```sh
scripts/handoff.sh <<'HANDOFF'
- 認証の直しは途中。残りは期限切れの扱い
- テストは通っているが、実際の画面ではまだ見ていない
HANDOFF
```

区切りが付いたときと、作業を止めるときに書き直す。

## 見る、片づける

```sh
scripts/show.sh
scripts/clear.sh -f
```

このブランチをマージする前に、気づきをきまりか案件のスキルに直してから
clear.sh -f で消す。残したままマージしない。
