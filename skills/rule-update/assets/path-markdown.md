- H1 の見出しを書かない
- 見出しを疑問形にしない
- 太字や飾りの記号と絵文字を使わない
- 全角のダッシュと不要なかぎかっこを使わない
- 一つの見出しに一つのことだけ書く
- すでに書いたことを言いかえて繰りかえさない
- 誰が何をするのかをはっきり書く
- 「AではなくB」「三つの観点から」のような同じ型を繰りかえさない
- 段落の長さと調子をそろえすぎない
- 読み手が使わない情報を書かない
- 例は一つで足りるなら一つにする
- 言いきれることをぼかさない
- 大げさな言い回しと横文字のたとえを使わない
