## 設定

```sh
sh scripts/stage.sh early
sh scripts/stage.sh
```

最初の命令でプロジェクト直下の `.aerie/stage.conf` に段階を書き、次の命令で今の段階を見る。設定がなければ `stable` とする。

## 段階

設定した段階の `assets/<段階>.md` を作業方針として使う。セッションの始めにも同じ方針が注入される。

- `early` 試作。互換性より試行を優先する
- `stable` 安定化。既存の動きと互換性を保つ
- `operation` 運用。利用者、データ、連携先を保全する

段階は作業のたびに聞き直さない。明示的な更新があるまで同じものを使う。段階に合わない安全策を勝手に足さない。
