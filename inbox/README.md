# Inbox

このディレクトリは、作業のために渡す参考資料・指示書の一時的な受け渡し窓口です。

ここに置いたファイルはプロジェクトの正本ではありません。Git 管理外の入力として扱い、
ソースコード・追跡対象の文書・テスト・Owlspec の記録から、ここに置いたファイルを参照したり
依存したりしません。

- 参考資料や補足文書はここに置く
- 指示書は、対象や適用範囲が分かるファイル名にする
- 機密情報や認証情報は置かない
- 依頼時に特定のファイルを優先して読む必要がある場合は、その旨を伝える

内容を正本として残したい場合は、別途その移動先と採用を明示してください。自動的に正本へ
昇格させたり、正本からこのディレクトリへのリンクを追加したりはしません。

作業開始時には、必要に応じてこのディレクトリの内容を確認します。
